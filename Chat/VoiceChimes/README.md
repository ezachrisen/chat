# Voice chimes

Selected from Kenney's Interface Sounds 1.0 pack:

- `dictation-started.wav`: `switch_002.ogg`
- `utterance-sent.wav`: `switch_001.ogg`
- `response-ready.wav`: `toggle_002.ogg`
- `segment-continues.wav`: three `bong_001.ogg` sounds, spaced 150 ms apart
- `handover.wav`: `confirmation_002.ogg`

The WAV files are 48 kHz stereo PCM. See `Kenney-Interface-Sounds-License.txt`
for the CC0 license.
